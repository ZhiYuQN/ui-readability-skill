# 交付前自检清单

按顺序执行，全部通过才交付。

---

## 0. 文本清点（先做，不要跳过）

把界面中所有文本节点按角色列成表。一个节点一行：

| # | 类型 | 原文 | 归档 | 处置 |
|---|---|---|---|---|
| 1 | 副标题 | 慢速听一句，按孔位试一句… | C+D | 删 |
| 2 | hint | 按所选音高以平均律播放… | D | 删 |
| 3 | 状态 | 已就绪 | A | 保留 |

`归档` 填 A–G。`处置` 只能是：**保留 / 删除 / 转结构 / 移出**。不允许出现"改写"以外的模糊项。

---

## 1. 七类覆盖检查

- [ ] 常驻主界面的文本，A/B 类占比 ≥ 80%
- [ ] 不存在 D 类（解释）长驻
- [ ] 不存在 E 类（版本号、日期、字节数、算法、格式）出现在主界面
- [ ] 应用内页不存在 F 类（金句、标语）
- [ ] 不存在 G 类（自夸、复述可见结构）

---

## 2. 数量红线

- [ ] 首屏说明性文字 ≤ 1 句，且为 B 类
- [ ] 单视图 `.hint` ≤ 3 处，每处 ≤ 20 字
- [ ] 一个区域只有 1 个主按钮
- [ ] 不存在连续 2 段以上的说明性正文
- [ ] 全站装饰性英文 eyebrow ≤ 1 处

---

## 2b. 排版与可读性（中文专项）

**字号**

- [ ] 没有任何中文 < 12px
- [ ] 正文 ≥ 15px（16px 为基准）
- [ ] 单视图字号层级 ≤ 4，取值 ≤ 5 种
- [ ] 相邻层级字号比值 ≥ 1.2（如 18 / 20 需合并或拉开）
- [ ] 层级由「字号 + 字重 + 灰度」三者共同表达，未只调字号

**行距与节奏**

- [ ] 正文行高 1.65–1.75；大标题 1.2–1.35（字号越大倍数越小）
- [ ] 段间距 ≥ 1em，且明显大于行距
- [ ] 标题上间距约为下间距的 4 倍（如 2.4em / 0.6em）
- [ ] 所有间距落在 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

**行长与折行**

- [ ] 正文行长 28–36 个汉字（`max-width: 34em`）
- [ ] 未用 `ch` 限制中文宽度
- [ ] 长段未使用 `text-align: justify`
- [ ] 长段未居中（居中仅限标题与 ≤ 3 行短提示）
- [ ] 数字与单位未在中间断行（`white-space: nowrap`）

**字距与字重**

- [ ] 中文正文 `letter-spacing: 0`；仅全大写英文小标签用 `+0.08em`
- [ ] 未使用 300 及以下字重
- [ ] 计时器 / 进度数字启用 `font-variant-numeric: tabular-nums`

**灰度与对比度**

- [ ] 正文对比度 ≥ 7:1；辅助小字 ≥ 4.5:1
- [ ] 未用 `#999` 在白底写中文（2.85:1）
- [ ] 正文未使用纯黑 `#000`（用 `#1a1a1a`–`#222`）
- [ ] 暗色主题正文未使用纯白 `#fff`
- [ ] 颜色不是唯一的信息载体（另有图标 / 文字 / 位置）

## 3. 重复检查

同一信息是否在多处出现？

- [ ] label 与 placeholder 不重复（placeholder 只放示例值，不放功能名）
- [ ] 按钮文案与旁边 hint 不重复（写了 `↩ 回到当前音` 就不要再解释它能干什么）
- [ ] 节标题与下方正文不互相复述
- [ ] 同一参数不在设置页与主界面各解释一遍

---

## 4. 结构替代检查

对每一条保留下来的说明文本，逐条确认：

- [ ] 它不能被默认值替代（已尝试把推荐值设为默认）
- [ ] 它不能被禁用态替代（`disabled` + `title` 能说明的不写句子）
- [ ] 它不能被图例替代（≤ 3 个符号时用图形图例）
- [ ] 它不能被分组替代（间距 / 分隔线 / 共享容器能表达的不写小标题）
- [ ] 它不能被空状态替代（"下一步点哪里"做成按钮）

> 任一项本可替代却仍写成文字 → 回退重做。

## 5. 命令扫描（可直接执行）

```bash
# 自夸与空承诺
rg -n "清晰|系统性|完整|优雅|轻松|简单易|一站式|全方位|极致|专业级|高效|智能|零基础" \
   --glob '*.{html,vue,jsx,tsx}'

# 解释腔
rg -n "这是一个|本页面|本工具|该功能|您可以|支持多种|通过.*实现|值得注意的是|简单来说" \
   --glob '*.{html,vue,jsx,tsx}'

# 把操作写成句子
rg -n "点击此处|请点击|请先|建议您|只需|即可|如果需要" \
   --glob '*.{html,vue,jsx,tsx}'

# 实现细节泄漏
rg -n "MiB|KB|毫秒|3\.5 秒|平均律|Ogg|版本|更新于|生成于|算法|采样率" \
   --glob '*.{html,vue,jsx,tsx}'

# hint 密度
rg -c 'class="[^"]*hint' --glob '*.{html,vue,jsx,tsx}'
```

**排版扫描**

```bash
# 过小字号（< 12px 一律有问题；< 15px 的正文有问题）
rg -n "font-size:\s*(1[01](\.\d+)?px|[0-9](\.\d+)?px)" --glob '*.{css,scss,vue,html}'

# 所有字号声明，用于统计层级数量
rg -o "font-size:\s*[^;]+" --glob '*.{css,scss,vue}' | sort | uniq -c | sort -rn

# 行高过紧
rg -n "line-height:\s*(1(\.[0-4]\d*)?|[0-9]{2}%)" --glob '*.{css,scss,vue}'

# 中文正字距
rg -n "letter-spacing:\s*[^0;][^;]*" --glob '*.{css,scss,vue}'

# 细字重
rg -n "font-weight:\s*(100|200|300|light|thin)" --glob '*.{css,scss,vue}'

# 两端对齐 / 危险灰度
rg -n "text-align:\s*justify|#999|#9a9a9a|#aaa|#b0b0b0" --glob '*.{css,scss,vue}'

# 行长用 ch 限制中文
rg -n "max-width:\s*[0-9]+ch" --glob '*.{css,scss,vue}'

# 非 4 倍数间距（抽查）
rg -o "(margin|padding|gap)[^:]*:\s*[0-9]+px" --glob '*.{css,scss,vue}' | rg -v ":\s*(4|8|12|16|24|32|48|64)px"
```

字号清单那一条尤其有用：肉眼看过一长串 `uniq -c` 之后，层级是否失控立刻可见。

命中项逐条确认：**是 B 类吗？** 不是就处理掉。排版命中项逐条对照 `typography.md` 的修正表。

## 6. 主路径回归（人工模拟）

假装第一次打开页面，**不看任何说明文字**，完成这些动作：

- [ ] 我能在 3 秒内找到主操作
- [ ] 我不用读段落就知道每个输入框填什么单位
- [ ] 我能分清主按钮与次按钮
- [ ] 出错时我知道下一步点哪里
- [ ] 等待时我知道系统没死
- [ ] 空列表时我知道怎么开始

任一项失败 → 说明删过头了，需要把信息**转成结构**补回来（不是加回文字）。

**可读性回归**（把页面缩到 75%，或退后 1 米看）

- [ ] 一级标题在一屏里只有一个是最重的
- [ ] 能一眼分出"标题 / 正文 / 辅助"三档，不用眯眼
- [ ] 辅助小字仍可辨认，不需要凑近
- [ ] 正文换行处不串行（行长合适）
- [ ] 段落之间有明显呼吸，不是一堵墙

## 7. 最后一道：AI 味自检

读一遍保留下来的每一句话，问：

- [ ] 它像产品经理写的界面，还是像 AI 在解释自己的作品？
- [ ] 有没有"需要注意的是""值得一提的是""总的来说"这类过渡句？（有 → 全删）
- [ ] 有没有一句是在向用户保证"我不会误导你"？（有 → 全删）
- [ ] 有没有形容词在夸这个界面本身？（有 → 全删）
- [ ] 把这句话念出来，真人会这么说吗？

> 最后一条最有效：**真人不会对使用者解释自己刚做的东西好在哪。**

## 报告格式

交付时附两行量化结论：

```
减注：清点 31 条，删 11 条，转结构 6 条，移出 2 条，保留 12 条；可见字数 420 → 90。
排版：层级 6 → 4；正文 13 → 16px；行高 1.4 → 1.7；行长 90 → 34 字；辅助色 #999 → #6b746f。
被删原文：……
```

列出被删原文，方便用户复核是否误删。

排版改动若影响视觉，需说明"省下的空间分配到了哪里"（留白 / 字号 / 行高），避免被理解为单纯缩小或放大。
