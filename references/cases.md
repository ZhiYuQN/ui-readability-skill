# 案例库：真实界面中的注脚文本

来源：一个真实的单文件课程应用（HTML + 原生 JS，约 3.5k 行，8 个视图）。
以下为原文摘录，选择器与 DOM 结构通用，可直接对照同类项目。

每组格式：**原文 → 判罚 → 理由 → 改写**。

---

## 案例 1｜用一整张卡片解释一个链接

```html
<div class="card">
  <span class="eyebrow">READ WITH CONTEXT</span>
  <a href="#library/p10" class="text-link">选择完整作品与版本 →</a>
  <p class="hint">简化片段用于学习；完整谱保留作曲家原貌。</p>
</div>
```

**判罚**：D 类（解释）+ F 类（装饰性 eyebrow）+ G 类（自述设计意图）。

**理由**：一张 180×90px 的卡片只承载一个链接。`READ WITH CONTEXT` 是可删的英文装饰；`简化片段用于学习；完整谱保留作曲家原貌` 是设计者在解释自己的取舍，用户不需要知道取舍，只需要知道"完整版在哪"。视觉重量远超信息价值，直接挤压右侧播放区。

**改写**：
```html
<a href="#library/p10" class="text-link">完整作品与版本 →</a>
```
卡片降为行内链接，删除 eyebrow 与 hint。主内容区宽度回收约 200px。

## 案例 2｜把工程日志写进界面

```js
sourceLine.textContent = '材料 / 署名：' + meta.source;
// 渲染结果：材料 / 署名：原一页通教学材料；2026-10-24 结构复核
```

**判罚**：E 类（元数据）。日期与"结构复核"是版本管理事实。

**改写**：移入 `#sources` 版本表；界面只保留 `title` 属性供 hover 查看署名，或整行删除。

判据：**用户据此能做任何决策吗？** 不能 → E 类。

## 案例 3｜一段散文解释了 5 个本该可视化的东西

```html
<p class="hint">孔位：实心圆＝手指盖孔，空心圆＝放开；方块 K 实心＝按键打开半音孔。
123｜456 是从笛头向足管的孔号。播放时谱面会跟着当前乐符移动；手动滑动会暂停跟随 3.5 秒，
点「回到当前音」可立刻找回。横向滑动可读完整谱行；B 是选段的结束边界。</p>
```

**判罚**：C + D + E 混合，一条段落承载 5 个不相关主题。

**逐句拆**：
| 句 | 问题 | 处置 |
|---|---|---|
| 实心圆＝盖孔… | 图例用文字写，位置远离图形 | 转：图形旁 3 个微型图例 |
| 123｜456 是从笛头向足管 | 真实约束，但可内联进孔位图标号 | 转：孔位图直接标 1–6 |
| 跟随乐符移动 / 手动滑动暂停 3.5 秒 | 暴露实现参数 | 删 3.5 秒；行为靠按钮自解释 |
| 点「回到当前音」可立刻找回 | 复述按钮文案 | 删（按钮已写着） |
| B 是选段的结束边界 | 复述 A/B 面板已写的 `B · 终点` | 删（信息重复） |

**改写**：整段删除。补两个结构件：
```html
<div class="legend">
  <i class="dot filled"></i><i class="dot open"></i><i class="key">K</i>
</div>
```
`#follow-back` 按钮已有 `↩ 回到当前音` 文本，无需再次解释。

## 案例 4｜把免责声明当副标题

```js
heading('PLAY / LISTEN / REPEAT', '让音符，连接到手指',
  '慢速听一句，按孔位试一句，再隐藏提示。参考声可选择现代长笛真人采样或电子参考音；' +
  '实际吹奏仍要用耳朵判断音色与音准。')
```

**判罚**：C 类前半 + **AI 式免责**后半（`实际……仍要……`）。

**理由**：前半描述的操作，界面上的播放 / 循环 / 节拍器按钮已经实现；后半是典型的"AI 怕被指责而加的话"，对操作零帮助，且暗示用户可能误解工具用途。

**改写**：`h1` 已是完整语义（"让音符，连接到手指"），副标题整句删除。heading 只留标题 + eyebrow。

**规律**：出现 `实际……仍要……`、`请注意……`、`本工具不能替代……` 时，几乎必然是免责噪声。

## 案例 5｜设置面板里的格式说明书

```html
<p class="hint">VSCO 2 CE · CC0。内嵌音源为 Ogg Vorbis 压缩版（约 0.8 MiB，保留原循环点与音高），
随附 WAV 为 5.8 MiB 无损原件。源采样以 440 Hz 为基准，按顶部所选音高调整播放；
这是现代长笛音色。音准与拍频工具使用稳定的电子参考音。</p>
```

**判罚**：E 类（授权 + 格式 + 体积 + 基准频率，五项元数据）。

**理由**：用户在这个面板里只做两件事——换音色、试听。格式与体积对这两件事没有任何影响。

**改写**：
```html
<p class="hint">CC0 · VSCO 2 CE　<a href="#sources/vsco-flute">音源与授权 →</a></p>
```
其余全部搬进 `#sources` 页。合规署名保留一行即可。

## 案例 6｜诗学金句

```html
<p class="flute-note">慢速、清楚、可以重复；每次只解决一个问题。</p>
```

**判罚**：F 类（修辞）。

**理由**：零信息，出现在"今日练习"卡片底部，占一整行。它不改变任何操作，也不消除任何困惑。此类文本的问题不是"不好"，而是**放错层级**：属于品牌语气，不属于工具界面。

**改写**：删。若确需学习氛围，放首次进入的引导层，一次性展示后不再出现。

## 案例 7｜侧栏对进度条的复述

```html
<div class="side-progress">
  <div><span>课程自检</span><b id="progress-count">0 / 48</b></div>
  <progress id="course-progress" max="48" value="0"></progress>
  <small>记录掌握情况，按自己的节奏学习。</small>
</div>
```

**判罚**：G 类。`记录掌握情况` 复述进度条的功能；`按自己的节奏学习` 是空话。

**改写**（**转 ≠ 删**的示范）：
```html
<small>下一课：持笛与呼吸 →</small>
```
把"解释这个组件在干什么"换成"指向下一个动作"。信息量从 0 提升到 1（真实导航），字数不变。

## 案例 8｜复述可见结构的小标题

```js
heading('CURRICULUM / 01—08', '从第一声，到高级研习',
  '每课都有操作步骤、自检和练习任务。可按路线推进，也可直接查阅正在遇到的问题。')
```

**判罚**：G 类。

**理由**：用户点进课程页，右侧立即看到"一步一步做 / 做到什么程度，再往下走 / 遇到困难时"三个小节。这句副标题在复述它自己。后半句"也可直接查阅"更是把左侧导航的存在解释了一遍。

**改写**：删除副标题。空出的位置给真实筛选项（按阶段 / 按难度 / 只看未完成），把解释换成功能。

## 案例 9｜半句有用、半句废话

```html
<p class="hint">BPM 按你选择的主拍计数。6/8 通常可设为 2 拍 × 3 细分；每个点代表一大拍。</p>
```

**判罚**：B 类（6/8 建议）与 D 类（控件复述）混杂。

**逐句**：
- `BPM 按你选择的主拍计数` → 复述 `每小节拍数` 输入框的语义，删。
- `6/8 通常可设为 2 拍 × 3 细分` → 真实决策帮助，**保留**。
- `每个点代表一大拍` → 指示灯的点数已可视化，删。

**改写**：
```html
<p class="hint">6/8：拍数 2 × 细分 3。</p>
```
从 42 字降到 14 字，信息密度提升 3 倍。

**规律**：长 hint 中通常只有 1/3 是真 B 类。逐句过筛，不要整段保留或整段删除。

## 案例 10｜状态 + 指令混合（应拆分）

```js
$('#play-status').textContent = '已就绪 · 点击播放，或先点一个音符。';
```

**判罚**：A 类（已就绪）合格，后半 `点击播放，或先点一个音符` 是 C 类指令。

**理由**：状态栏的职责是报告状态，不是发号施令。指令应当由空状态或首次引导承担。

**改写**：
```js
$('#play-status').textContent = '已就绪';
```
教学职责交给乐谱区首次渲染时的 coach mark（可关闭、只出现一次）。

## 对照组｜这些必须保留

```html
<p id="sample-status" role="status">采样将在第一次试听时载入。</p>
```

**判为 A 类，保留。** 它回答的是"我点了试听为什么没声音"——一个用户**真实会遇到的困惑**。删掉它，用户会以为功能坏了。

```html
<p class="hint">删除后无法恢复。</p>
```
**判为 B 类，保留。** 保护性约束。

**这就是分界线**：

> 能回答"为什么现在是这样"的留下；
> 只回答"这个功能是什么"的删掉。
