# 文案分类识别表 & 转换手法

配合 `SKILL.md` 使用。第一部分用于**判定**，第二部分用于**改写**。

---

## 一、七类的识别特征

### A 状态（STATE）— 保留

特征：描述"此刻"，随时间变化，通常用 `role="status"` / `aria-live`。

- `已停止 · 4 拍/小节`
- `采样将在第一次试听时载入。`
- `正在排谱…`
- `0 / 48`
- `已通过本课自检`

判据：**它会变化吗？** 会 → A 类。

要求：A 类不能只靠文字，必须有视觉对应（色点、进度条、图标、按钮态）。只有文字的状态等于没设计。

### B 约束（CONSTRAINT）— 保留，一句以内

特征：解释边界、后果、限制，回答"为什么不能 / 为什么是这样"。

- `删除后无法恢复。`
- `B 必须大于 A。`
- `Firefox 下需手动允许音频播放。`
- `6/8：拍数 2 × 细分 3。`（真实决策帮助）

判据：**缺了它用户会做错事或卡住吗？** 会 → B 类。

### C 指令（INSTRUCTION）— 转成结构

特征：祈使句、步骤描述、"先…再…"、"建议…"。

- `慢速听一句，按孔位试一句，再隐藏提示。`
- `点击音符，可单独听音并查看指法。`
- `按 Ctrl+A 全选。`
- `建议每次练习 15 分钟。`

改写路径（按优先级）：默认值 → 禁用态 → 空状态 → 就地 hover → 一次性引导 → 最后才是短句。

### D 解释（EXPLANATION）— 删 / 降级

特征：陈述句式，说明功能是什么、为什么这样设计、技术背景。

- `参考声可选择现代长笛真人采样或电子参考音；实际吹奏仍要用耳朵判断音色与音准。`
- `按所选音高以平均律播放；真人采样来自现代长笛。`
- `简化片段用于学习；完整谱保留作曲家原貌。`
- `手动滑动会暂停跟随 3.5 秒。`

判据：**它是"设计者想让你知道的"，还是"你必须知道才能操作的"？** 前者 → D 类。

典型病灶：**用一整张卡片解释一个链接**。卡片承载的视觉重量远大于信息价值。

### E 元数据（METADATA）— 移出

特征：版本、日期、来源、署名、体积、格式、编码、采样率、算法名、授权条款。

- `材料 / 署名：原一页通教学材料；2026-10-24 结构复核`
- `内嵌音源为 Ogg Vorbis 压缩版（约 0.8 MiB）`
- `源采样以 440 Hz 为基准`

处置：进 `#about` / `#sources` / 版本表。主界面只留一行合规必需的署名（如 `CC0 · VSCO 2 CE`）。

### F 修辞（RHETORIC）— 落地页 1 处，应用内全删

特征：标语、金句、抒情、氛围铺垫、对仗句。

- `慢速、清楚、可以重复；每次只解决一个问题。`
- `从第一声，到自己的诠释。`
- `让音符，连接到手指。`

边界：**落地页 / 首页 hero 允许保留 1 段定位文案 + 1 处 slogan**。一旦进入工具页、设置页、练习页，全删。

### G 空承诺（EMPTY CLAIM）— 全删

特征：自我评价、凑数标语、正确但无行动指向的话。

- `八个阶段，一条清楚的路线`
- `每课都有操作步骤、自检和练习任务。`
- `记录掌握情况，按自己的节奏学习。`
- `零基础也能轻松上手`
- `一站式解决`

**G 类判据（机械可执行）**：把句子里的形容词与程度副词删掉，剩下的名词短语是否还提供新信息？
- `八个阶段，一条清楚的路线` → 删掉"清楚的"，剩"八个阶段，一条路线" —— 而八个阶段在下方网格已经可见 → 空承诺，删。
- `每课都有操作步骤、自检和练习任务` → 用户翻一页就看见了 → 复述可见结构，删。

## 二、正则检索表（用于批量扫描既有代码）

```bash
# G 类：自夸与空承诺
rg -n "清晰|系统(化|性)|完整|优雅|轻松|简单易|一站式|全方位|极致|专业级|高效|智能" \
   --glob '*.{html,vue,jsx,tsx}'

# D 类：解释腔开头
rg -n "这是一个|本页面|本工具|该功能|您可以|您可|支持多种|采用.*方式|通过.*实现" \
   --glob '*.{html,vue,jsx,tsx}'

# C 类：把操作写成句子
rg -n "点击此处|请点击|请先|建议您|只需|即可|如果需要" \
   --glob '*.{html,vue,jsx,tsx}'

# E 类：实现细节泄漏
rg -n "MiB|KB|MB|秒|毫秒|Hz|版本|更新于|生成于|API|算法|压缩|编码|格式" \
   --glob '*.{html,vue,jsx,tsx}'

# F 类：装饰性语气
rg -n "值得注意的是|需要指出的是|总的来说|换句话说|简单来说|事实上" \
   --glob '*.{html,vue,jsx,tsx}'

# 结构信号：hint 类小字密度
rg -c 'class="[^"]*hint' --glob '*.{html,vue,jsx,tsx}'
```

命中不等于必须删，命中 = 进入人工复核队列。

## 三、十条转换手法的具体做法

### 1. 单位内联
```html
<!-- 前 -->
<label>速度 · 四分音符 / 分<input type="number" value="60"></label>
<!-- 后 -->
<label class="bpm"><input type="number" value="60"><span>♩/分</span></label>
```

### 2. 图例就地化
```html
<!-- 前 -->
<p class="hint">实心圆＝手指盖孔，空心圆＝放开；方块 K＝按键打开半音孔。</p>
<!-- 后 -->
<div class="legend">
  <i class="dot filled"></i><i class="dot open"></i><i class="key"></i>
</div>
```
图例 ≤ 3 个符号时不需要文字；符号超过 3 种才配 2 字标签。

### 3. 默认值即教学
```html
<!-- 前 --><p class="hint">建议预备 4 拍再开始。</p>
<!-- 后 --><option value="4" selected>4 拍（推荐）</option>
```

### 4. 禁用态即解释
```html
<!-- 前 --><p class="hint">请先选择一个音符再播放。</p>
<!-- 后 --><button id="play" disabled title="先选择一个音符">▶ 播放</button>
```

### 5. 分组即语义
用间距（8 / 24 / 48 三级）+ 分隔线替代小标题文本。**小标题也是文本预算**，能用间距分组的就不用小标题。

### 6. 文案即动作
- ❌ `点击此处开始播放音频` → ✅ `▶ 播放`
- ❌ `提交你填写的信息` → ✅ `保存`
- ❌ `这是一个用于切换音色的下拉框` → ✅ `音色`

### 7. 空状态即引导
```html
<!-- 前 --><p class="empty">暂无练习记录，请先完成一次练习后再查看。</p>
<!-- 后 --><div class="empty"><p>还没有记录</p><a class="button" href="#practice">开始第一次练习</a></div>
```

### 8. 渐进披露
长解释（> 40 字）一律进 `<details>`：
```html
<details class="more"><summary>为什么用 415 Hz</summary><p>…</p></details>
```
`<summary>` 本身就是一句短标签，不占常驻预算。

### 9. 一次性引导
仅首次进入时弹出，落地 localStorage 标记，可关闭，不再出现。绝不用永久常驻段落承担教学职责。

### 10. 状态栏代替叙事
```html
<!-- 前 --><p>节拍器当前处于停止状态，每小节四拍。</p>
<!-- 后 --><p role="status">已停止 · 4 拍/小节</p>  <!-- 用 · 分隔，去掉主谓 -->
```
状态文本统一格式：`<状态> · <关键参数>`，不超过 12 字。

## 四、改写后的自检三问

对每一处保留的文本：

1. 它在回答 A（此刻如何）或 B（为何受限）吗？不是 → 再删一次。
2. 它能否被一个图标、一个默认值、一次分组替代？能 → 替代。
3. 删掉它，新用户会不会做错事？不会 → 删。
