# 字号层级与可读性规范

面向中文界面的排版要求。核心约束：**中文不是拉丁文**，Inter / Tailwind 的默认尺度不能照搬——
方块字的笔画密度高、没有词间空格、不适合负字距与斜体，最小可读字号更大。

---

## 一、中文的字号红线

| 场景 | 下限 | 舒适区 | 说明 |
|---|---|---|---|
| 辅助信息（单位、时间戳、脚注） | **12px** | 12–13px | 低于 12px 汉字笔画粘连，笔画数 >12 的字（"繁""攒"）会糊成块 |
| 控件文本（按钮、输入、标签） | **13px** | 14–15px | 低于 13px 时表单标签的点击区与文字视觉失衡 |
| 正文 | **15px** | 16–17px | 16px 是中文长文本的最优基准 |
| 小标题 | 18px | 19–22px | |
| 区块标题 | 22px | 24–30px | |
| 页面标题 | 28px | 32–40px | 工具页建议 ≤ 32px |

**硬红线：任何中文文本不得小于 12px。** 若因放不下而想缩小，说明该段文字本身不该存在（见 `SKILL.md` 支柱一）。

拉丁文可以到 11px，中文不行。这条差异必须显式处理，不能沿用英文模板的 `text-xs = 12px` 就当作安全边界。

---

## 二、层级数量是预算

**一个视图内，字号层级不得超过 4 级**（不含品牌 logo）。超过 4 级时，用户无法建立优先级——所有东西都在喊。

推荐的四级最小集：

| 层级 | 角色 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|---|
| L1 | 区块标题 | 24–30px | 1.3 | 700 | 一屏一个 |
| L2 | 小标题 / 引导段 | 18–20px | 1.45 | 600 | 2–4 个 |
| L3 | 正文 / 控件 | 15–16px | 1.7 | 400 | 主体 |
| L4 | 辅助 | 12–13px | 1.5 | 400 | 单位、状态、脚注 |

**层级跳跃规则**：相邻两级字号比值 ≥ **1.2**。
18 与 20 不是两个层级，是排版失误。要么跳到 22，要么合并。

**层级不能只靠字号**。三个维度共同表达：

```
层级 = 字号 × 字重 × 颜色（不透明度/灰度）
```
只调字号的界面，看起来像所有文字随机大小；三维同时调，层级才立得住。

---

## 三、行高：字号越大，倍数越小

中文行高普遍需要比英文大 0.15–0.25。原因是汉字无升降部、字面率高，行与行之间缺少"天然空隙"。

| 字号 | 行高 |
|---|---|
| 12–13px | 1.6–1.75 |
| 14–16px | 1.65–1.75 |
| 17–20px | 1.55–1.65 |
| 22–26px | 1.4–1.5 |
| 28–40px | 1.2–1.35 |
| 44px+ | 1.05–1.15 |

**反面**：单行标题用 1.7 会散架；14px 正文用 1.3 会挤成一团墨。

---

## 四、行长：25–40 个汉字

- 最优：**28–36 字/行**
- 可接受：25–40 字
- 超过 45 字：眼球回归下一行时容易串行（跳行阅读失败）
- 低于 20 字：断行过频，节奏碎裂

实现：

```css
.prose { max-width: 34em; }   /* em 在中文语境 ≈ 字数，34em ≈ 34 字 */
```

⚠️ **不要用 `ch`**。`ch` 是数字 "0" 的宽度，对全角汉字的估算严重偏小——`62ch` 的中文实际约 100 字/行。

---

## 五、段间距必须大于行间距

最常见的排版塌陷：段落之间只有行高分隔，一屏文字变成一堵墙。

```css
p { margin: 0 0 1em; line-height: 1.7; }  /* 段距 ≈ 1 个行高 */
```

标题的邻近性（**标题归属于下方内容**，不归属上方）：

```css
h2 { margin: 2.4em 0 .6em; }   /* 上 2.4 > 下 0.6 */
```

上小下大 → 标题看起来是上一段的尾巴。这是可读性事故，不是风格问题。

---

## 六、字重：中文只有三档

多数中文字体只提供 400 / 500 / 700。请求 600 会被合成或回退，结果不可控。

- 正文 400
- 强调 700（不要用 500 做层级，14px 下肉眼几乎看不出）
- **禁止 300 及以下**：中文细体在 16px 以下笔画断裂
- 相邻层级的字重差至少 300（400 → 700）；400 → 500 视为同层

需要更细的层级时，用**颜色**补充，不要硬凑字重。

---

## 七、字间距：中文不加，英文小标签才加

| 对象 | letter-spacing |
|---|---|
| 中文正文 / 标题 | `0`，标题可 `-0.01em` |
| 中文任何字号的正字距 | **禁止**（汉字会散架） |
| 全大写拉丁小标签（eyebrow） | `+0.08em ~ +0.12em` |
| 数字表格、计时器 | `0` + `font-variant-numeric: tabular-nums` |

`tabular-nums` 是硬要求：进度数字、BPM、时间码若用比例数字，跳动时会左右抖动。

---

## 八、灰度与对比度

层级靠三种灰度表达，不靠随手写的十六进制灰。

```css
:root{
  --ink-1: #1c2321;   /* 正文      对白底 ≈ 14:1 */
  --ink-2: #4a5350;   /* 次要      对白底 ≈ 8:1  */
  --ink-3: #6b746f;   /* 辅助      对白底 ≈ 5:1，仅限 ≥13px */
  --line:  #dfe3e1;   /* 分隔线    不用来写字 */
}
```

对比度底线（WCAG）：

| 内容 | 最低 | 建议 |
|---|---|---|
| 正文 | 4.5:1（AA） | **7:1（AAA）** |
| 辅助小字 | 4.5:1 | 4.5:1，不得低于 3:1 |
| 禁用态 | 豁免 | 但仍需可辨认 |

**禁止 `#999` 放在白底上写中文**：对比度仅 **2.85:1**，且 12px 汉字在此对比度下基本无法阅读。
参考锚点：`#767676` on `#fff` = 4.54:1（刚好 AA）；`#595959` = 7:1（AAA）。

**禁止纯黑正文**：`#000` on `#fff` = 21:1，长文阅读产生眩光，用 `#1a1a1a`~`#222` 区间。

暗色主题反向处理：

```css
[data-theme="dark"]{
  --ink-1: #e8ebe9;  /* 不要用 #fff，纯白在暗底上会溢光 */
  --ink-2: #a7b0ac;
  --ink-3: #7f8884;
}
```

## 九、中西混排

- 中英文之间留 1/4 空格（`巴洛克长笛 A4 = 415 Hz`），用 `&nbsp;` 或细空格 `&#8201;`
- 中文标点不出现在行首：`line-break: strict;`
- **禁止 `text-align: justify`**：中文两端对齐会拉伸字间距，产生"稀疏的裂缝"
- 数字与单位不断行：`<span style="white-space:nowrap">415 Hz</span>`
- 不滥用斜体：中文无真斜体，伪斜体是倾斜的方块字，只用于书名/外文术语

---

## 十、垂直节奏：4px 网格

所有 `margin` / `padding` / `gap` 取 4 的倍数。间距档位只允许：

```
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
```

超出这 8 个值的间距（如 18px、27px、35px）会让整页失去节奏感，且难以维护。

行高用无单位倍数（`1.7`），容器 padding 走网格，两者的取整误差可接受。

## 十一、可复制的 token

```css
:root{
  /* 字号：四层最小集 */
  --fs-aux: 12.5px;   /* L4 辅助 */
  --fs-body: 16px;    /* L3 正文 */
  --fs-sub: 19px;     /* L2 小标题 */
  --fs-head: 26px;    /* L1 区块标题 */

  /* 行高 */
  --lh-aux: 1.5;
  --lh-body: 1.72;
  --lh-sub: 1.45;
  --lh-head: 1.3;

  /* 字重 */
  --fw-body: 400;
  --fw-strong: 700;

  /* 灰度 */
  --ink-1: #1c2321;
  --ink-2: #4a5350;
  --ink-3: #6b746f;

  /* 间距网格 */
  --s1: 4px;  --s2: 8px;  --s3: 12px; --s4: 16px;
  --s6: 24px; --s8: 32px; --s12: 48px; --s16: 64px;

  /* 行长 */
  --measure: 34em;
}
```

四级之外的展示型标题（hero 40px+）只允许出现在落地页首屏，工具页不使用。

## 十二、常见错误清单

| # | 错误 | 后果 | 修正 |
|---|---|---|---|
| 1 | 中文 11–12px 当正文 | 笔画糊成一团 | 正文 ≥ 15px，靠减注腾空间 |
| 2 | 5 种以上字号 | 无优先级 | 压到 4 级 |
| 3 | 18px 与 20px 并列为两级 | 看起来像失误 | 拉开到 1.2 倍以上 |
| 4 | 中文正文 `line-height: 1.4` | 行间粘连 | 1.65–1.75 |
| 5 | 中文 `letter-spacing: .05em` | 字散架 | 归零 |
| 6 | `max-width: 62ch` 限中文行长 | 实际 100 字/行 | 用 `34em` |
| 7 | `#999` 写 12px 中文 | 2.85:1，不可读 | 换 `#6b746f` 并提到 13px |
| 8 | 段间距 = 行间距 | 文字成墙 | 段距 ≥ 1em |
| 9 | 标题上下间距相等 | 标题归属错误 | 上 2.4em / 下 0.6em |
| 10 | `text-align: center` 用于长段 | 每行起点漂移 | 仅标题与 ≤3 行的短提示 |
| 11 | 比例数字做计时器 | 数字宽度跳动 | `tabular-nums` |
| 12 | 中文 `font-weight: 300` | 细笔画断裂 | ≥400 |
| 13 | 间距 18 / 27 / 35px | 无节奏 | 归入 4px 网格 |
| 14 | 暗底用 `#fff` 正文 | 溢光、刺眼 | `#e8ebe9` |

## 十三、排版与文案的耦合（重要）

文本过载的第一个后果不是"读得累"，而是**字号被迫缩小**。

一个真实路径：说明文字越写越多 → 一屏放不下 → 把 `.hint` 从 14px 压到 12px → 每一条都变难读 → 又加更多解释"提升可理解度" → 继续压字号。

破解点在第一步。**删掉 60% 的文字后，省下的空间应该还给留白与字号，而不是继续塞新内容。**

```
减注前：hint 12px / 行高 1.4 / 行长 90 字 / 8 处
减注后：hint 13px / 行高 1.5 / 行长 34 字 / 3 处
```

同一个页面的阅读成本下降幅度远超"字数减少 60%"——因为**阅读成本 ≈ 字数 × 每字成本**，两个因子同时下降。

## 十四、实证：一个真实页面的排版体检

来源：同一个单文件课程应用的样式表（`--paper:#f4f3ed`、`--ink:#243d36`、`--muted:#667870`）。

| 检查项 | 实测 | 判定 |
|---|---|---|
| 正文字号 | `.lead` 16px（课程页降至 14–15px） | 合格 |
| 辅助字号 | `.hint` / `small` / `.study-note` = 12px | 临界 |
| 极小字 | `.score-finger .hint` = **10px**，`.sound-settings-body .hint` = **11px** | **违规**（< 12px） |
| 正文对比度 | `#243d36` on `#f4f3ed` = **10.52:1** | 优秀（超 AAA） |
| 辅助对比度 | `#667870` on `#f4f3ed` = **4.21:1** | **不达 AA**（需 4.5:1） |
| 行长 | `.lead` `max-width:760px` ÷ 16px = **47.5 字** | **超长**（> 45 会串行） |
| 正文行高 | `.lead` `1.95`（31px 行高） | 偏大（建议 1.7） |
| 字号层级 | 10 / 11 / 12 / 14 / 15 / 16 / 18 / 20 / 24 / 30+ | **失控**（远超 4 级） |

### 因果链：为什么 10px 会出现

`.score-finger .hint` 要装那句 168 字的指法说明——"孔位：实心圆＝手指盖孔，空心圆＝放开；方块 K 实心＝按键打开半音孔……"。它必须挤在乐谱下方的窄条里，于是被压到 **10px**。

`.sound-settings-body .hint` 的 11px，对应的是那三段授权 / 格式 / 体积说明。

**每一个低于红线的字号，背后都对应一段该删的文本。** 这不是排版问题先发生、再导致文案问题，而是同一个病的两个症状。

### 修正目标

| 项 | 修正 | 依据 |
|---|---|---|
| `.hint` / `small` / `.study-note` | 12 → 13px；`--muted` `#667870` → `#5b6b64` | 对比度 4.21 → **5.06:1**，过 AA |
| `.score-finger .hint` | 10 → 12px，并删除长句改为三个图形图例 | 回到红线以上 |
| `.sound-settings-body .hint` | 11 → 12.5px，同时把三段元数据移出面板 | 回到红线以上 |
| `.lead` | `max-width: 760px` → `34em`；`line-height: 1.95` → `1.7` | 行长 47.5 → 34 字 |
| 字号档位 | 10 档压缩为 4–5 档 | 重建层级 |

减注后腾出的垂直空间应回填到：行高 1.7、段距 ≥ 1em、区块间距 ≥ 32px。**不回填新文案。**
