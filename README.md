# UI Readability

> 让 AI 写前端时少说废话，并且把话说清楚。

一个 Agent Skill（技能），给 AI 加两条约束：**界面上的说明文字要减到最少**，**保留下来的文字要真正好读**。

适用于任何由 AI 生成的面向用户的界面——HTML 单页、工具页、看板、表单、设置面板。

English: A skill that trims AI-slop commentary from user interfaces and enforces typographic legibility rules tuned for Chinese text.

---

## 它解决什么

AI 生成的界面有一种固定症状：满屏正确但无用的说明。

- 「本页面支持……」「您可以……」「需要注意的是……」
- 用一整张卡片解释一个链接
- 把版本号、文件格式、算法参数写进主界面
- 界面评价自己「清晰、系统、完整」

这些文字占地方、抢注意力，却不改变用户任何一步操作。而它们的真实代价往往被忽略：**文本一多，字号就被迫缩小**，于是每一条都更难读。

`阅读成本 ≈ 字数 × 每字成本`

两个因子必须同时降。

---

## 核心判据

处理任何一段界面文本，先归档，再决定：

| 类 | 定义 | 处置 |
|---|---|---|
| A 状态 | 现在正在发生什么 | 保留 |
| B 约束 | 为什么不能做、会有什么后果 | 保留，一句以内 |
| C 指令 | 你应该怎么操作 | 转成默认值 / 禁用态 / 空状态 |
| D 解释 | 这个功能是什么 | 删，或降级为 hover |
| E 元数据 | 版本、日期、体积、格式、授权 | 移出主界面 |
| F 修辞 | 标语、金句 | 落地页留 1 处，应用内全删 |
| G 空承诺 | 自评、复述可见结构 | 全删 |

只有 A、B 有资格常驻主界面。

最实用的一条单句判据：

> **能回答「为什么现在是这样」的留下；只回答「这个功能是什么」的删掉。**

例：`采样将在第一次试听时载入。` 留下（用户在等，需要知道为什么没声音）。
`按所选音高以平均律播放。` 删掉（用户换不了任何操作）。

## 排版数值速查

中文不是拉丁文。方块字笔画密度高、无词间空格、不适配负字距与斜体，最小可读字号更大——Inter / Tailwind 的默认值不能照搬。

| 项 | 要求 |
|---|---|
| 中文字号 | 任何文本 ≥ **12px**，正文 **15–17px** |
| 字号层级 | 单视图 ≤ **4 级**，相邻比 ≥ **1.2**（18 与 20 不是两级，是失误） |
| 行高 | 正文 1.65–1.75；22px+ 标题 1.2–1.35（字号越大倍数越小） |
| 行长 | **28–36 个汉字**（`max-width: 34em`；**不要用 `ch`**，会超长近一倍） |
| 段距 | ≥ 1em，且大于行距；标题上 2.4em / 下 0.6em |
| 对比度 | 正文 **7:1**，辅助小字 4.5:1（`#999` 白底仅 2.85:1，不可用） |
| 字重 | 中文实际只有 400 / 500 / 700；禁用 300 |
| 字距 | 中文 `0`；仅全大写英文小标签用 `+0.08em` |
| 间距 | 只允许 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 数字 | 计时器、进度启用 `tabular-nums` |

```bash
# Claude Code

# WorkBuddy
git clone https://github.com/ZhiYuQN/ui-readability-skill.git ~/.workbuddy/skills/ui-readability
```

## 使用

不需要显式调用，匹配到就会触发。也可以直接说：

- 「做这个页面，少写点说明」
- 「检查一下这个界面的文案有没有 AI 味」
- 「字号层级调一下，读起来太累」
- 「这个页面可读性怎么样」

### 两种模式

**写新界面**——前置约束，不是写完再删：

1. 每个可操作对象 = 一个控件 + 一个短标签
2. 自问：标签 + 默认值 + 相邻分组，够不够让人会用？够 → 不写提示
3. 只为 A、B 两类预留文本位置
4. 定 4 级字号写进 token，全程不用魔法数字

**审查既有界面**——清点 → 归档 → 判罚 → 转换 → 重排 → 回归，最后给出量化结论：

```
减注：清点 31 条，删 11 条，转结构 6 条，移出 2 条，保留 12 条；可见字数 420 → 90。
排版：层级 6 → 4；正文 13 → 16px；行高 1.4 → 1.7；行长 90 → 34 字。
```

## 一条反向护栏

这套方法很容易用过头，把页面削成白板。以下**只能精简，不能删**：

安全与授权声明、破坏性操作的后果、异步等待状态、错误信息的修复建议、空状态的唯一出路、落地页定位文案。

判定：**缺了它用户会做错事或卡死 → 留；缺了它只是少知道一点背景 → 删。**
